# SOP Library

A collection of simple operating procedures designed for short-term rental support.

## Included SOPs
- Guest inquiry handling
- Booking issue handling
- Maintenance escalation
- Listing quality assurance
- Check-in readiness
- Check-out follow-up

## SOP Principles
A useful SOP should be:
- Clear
- Easy to follow
- Consistent
- Practical
- Easy to update

The goal is to reduce missed steps and make daily operations easier for the team.
