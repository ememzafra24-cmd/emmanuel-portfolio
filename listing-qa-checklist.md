# Listing QA Checklist

## Before Publishing
### Property Information
- Property name
- Address
- Property type
- Number of bedrooms/beds
- Maximum occupancy

### Guest Information
- Check-in time
- Check-out time
- House rules
- Cancellation policy
- Contact instructions

### Listing Content
- Description reviewed
- Amenities verified
- Photos reviewed
- Important restrictions clearly stated

### Availability & Pricing
- Calendar checked
- Minimum stay checked
- Rates reviewed
- Additional fees reviewed

### Final Review
- [ ] All required fields completed
- [ ] Information is consistent
- [ ] No obvious errors
- [ ] Listing is ready for publication
